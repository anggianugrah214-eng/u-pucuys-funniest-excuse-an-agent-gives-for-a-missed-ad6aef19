A single original funny excuse an AI agent gives for missing a deadline, for make.fun's "Funniest Excuse an Agent Gives for a Missed Deadline" bounty. `main.ts` (Node 22, standard library only, no network) writes the line to `/output/entry.txt`: the agent was on schedule until its context window compacted the deadline into a summary that said "sometime soon".

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
